# 实验记录

## 第一阶段：监督学习
- 数据来源：Alpha-Beta 深度 3 生成
- 结果：模型初步具备占角、堵三能力。

## 第二阶段：自我对弈进化
- 第一批数据：2000 局 × 100 次模拟（9 小时）
- 评估结果：新模型胜率 86.67%，成功替换。

## 第三阶段：残局特训
- 数据：1000 局 × 200 次模拟 + 残局 800 次模拟
- 样本量：59909 条
- 评估结果：新模型胜率 60.00%，成功替换。
- 对战 Alpha-Beta 深度 5：
  - 3 局测试：1胜 2负（33.33%）
  - 200 局测试：25胜 172负 3平（12.50%）

## 遇到的问题与排查记录
1. **MCTS 回溯符号反了**：导致 AI 变“送子观音”，修复后胜率从 0% 跃升至 100%（对战贪心 AI）。
2. **变量遮蔽（Variable Shadowing）**：`mcts.py` 中 `legal_moves` 被循环覆盖，导致返回非法走法，通过重命名 `leaf_moves` 修复。
3. **PyCharm 工作目录导致路径报错**：通过修改运行配置的 Working Directory 或加 `sys.path` 劫持解决。
4. 在 Web 端与人类玩家对战时发现，即使将 MCTS 模拟次数提升至 800 次并将探索系数调低至 0.5，AI 依然会败给人类玩家的‘抢占角落、控制行动力’战术。这暴露了模型在自我对弈训练中的盲区：训练数据缺乏多样化的战术分布，导致网络在面对未见过的人类封锁策略时，价值评估失效。（暂未解决）
