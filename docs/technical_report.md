# AlphaZero 黑白棋 AI 技术报告

## 一、项目背景
本项目基于 DeepMind 的 AlphaZero 论文思想，从零实现了一个黑白棋（Othello）的深度强化学习系统。项目不依赖任何现成的 MCTS 或 RL 库，完全手写 MCTS、PUCT、自我对弈与训练循环。

## 二、核心算法
### 2.1 蒙特卡洛树搜索（MCTS）
- **Selection**：基于 PUCT 公式选择子节点。
- **Expansion**：使用神经网络输出的策略分布扩展节点。
- **Evaluation**：调用神经网络获取当前局面的价值评估。
- **Backpropagation**：回溯更新节点的访问次数与 Q 值。

### 2.2 策略/价值双头神经网络
- **输入**：3 个通道的 8x8 棋盘张量（己方棋子、对方棋子、当前玩家）。
- **网络结构**：2 层卷积 + 1 层全连接，输出策略头（64维概率分布）与价值头（[-1, 1] 标量）。
- **损失函数**：交叉熵损失（策略）+ 均方误差（价值）。

### 2.3 自我对弈与进化闭环
- **温度衰减**：前10步 temp=1.0，10-20步 temp=0.5，之后 temp=0.1，保证数据多样性。
- **Dirichlet 噪声**：根节点注入噪声，防止陷入局部最优。
- **动态残局特训**：剩余空格少于 12 时，模拟次数从 200 提升至 800，增强残局计算能力。
- **评估门控**：新模型胜率 > 55% 才替换旧模型。

## 三、实验设计与结果
### 3.1 训练数据
- 自我对弈局数：1000 局
- 单步模拟次数：200 次
- 总训练样本：59909 条

### 3.2 对战测试结果
| 对手 | 模拟次数 | 胜率 | 说明 |
| :--- | :--- | :--- | :--- |
| 贪心 AI | 100 | 100% | 基础测试 |
| 旧版模型 | 50 | 86.67% | 进化后自我超越 |
| Alpha-Beta 深度5 | 200 | **12.50%** | 低算力极限挑战（25胜/175负/3平） |

### 3.3 结果分析
在纯 Python 环境、算力仅为对手 1/50 的极端条件下，模型依然战胜了 Alpha-Beta 深度 5 共 25 局。这证明了神经网络在低算力下的高效推理能力。若将模拟次数提升至 800 次，模型胜率有极大概率发生质变。
